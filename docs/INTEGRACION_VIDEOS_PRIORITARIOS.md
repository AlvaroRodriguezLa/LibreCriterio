Un argumento mixto puede contener un mecanismo cubierto y un número o ejemplo histórico deliberadamente no incorporado; la última columna lo separa.

No es necesario reproducir cada metáfora ni cada puesta en escena para conservar una idea. Tampoco se añaden datos dudosos con el fin de que cada fila tenga un capítulo.
